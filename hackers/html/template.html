Eine Gruppe von Hackern behauptet, in einem kompromittierten "Hackers News Forum" tausende Kreditkartennummern erbeutet zu haben, und bietet die Liste zum Verkauf an. Ein anonymer Whistleblower hat Ihnen Kopien dieser Liste zugespielt. Sicherheitsforscher vermuten, dass ein großer Teil davon gefälscht ist: mit zufälligen Ziffern aufgefüllte Nummern, die die Beute größer erscheinen lassen sollen. Ihre Aufgabe ist es, diese Liste zu analysieren und die Anzahl der ungültigen Kreditkartennummern zu ermitteln, um das tatsächliche Ausmaß des Datenlecks besser einschätzen zu können.

Viele Fälschungen lassen sich erkennen, ohne eine Bank zu fragen: Jede echte Kreditkartennummer enthält eine Prüfziffer, die mit dem Luhn-Algorithmus berechnet wird, und echte Kartennummern sind immer zwischen 12 und 19 Ziffern lang. Eine Nummer, die eine dieser beiden Prüfungen nicht besteht, kann keine echte Karte sein.

Hintergrund: Der Luhn-Algorithmus

  1. Beginnend mit der vorletzten Ziffer wird jede zweite Ziffer (von rechts gezählt) mit 2 multipliziert. Ist das Ergebnis größer als 9, werden dessen Ziffern addiert (z. B. 7 · 2 = 14 → 1 + 4 = 5).
  2. Alle so erhaltenen Werte werden mit den nicht verdoppelten Ziffern aufsummiert.
  3. Ist die Summe durch 10 teilbar (Summe % 10 == 0), ist die Prüfziffer korrekt.

Den Algorithmus müssen Sie nicht selbst implementieren: Das Modul luhncheck kann mittels pip install luhncheck installiert werden und stellt die Funktion is_luhn(number) bereit. Sie erhält eine Kartennummer als String (nur Ziffern) und gibt True oder False zurück.

Aufgabe

{% include "file.html" %} implementieren Sie eine Funktion def checkFile(listenname):, die als Argument einen Dateinamen (type String) übergeben bekommt und diese Datei aus dem aktuellen Verzeichnis einliest. Die Datei enthält eine Liste von Kreditkartennummern, jeweils eine pro Zeile. Öffnen Sie diese Datei lesend und überprüfen Sie jede Nummer auf Gültigkeit:

  • Eine Nummer kann, wie auf einer echten Karte, durch Leerzeichen in Gruppen unterteilt sein (z. B. 4003 6000 0000 0014). Entfernen Sie alle Leerzeichen sowie den Zeilenumbruch am Ende der Zeile, bevor Sie die Nummer prüfen.
  • Eine Nummer ist ungültig, wenn sie (ohne Leerzeichen) weniger als 12 oder mehr als 19 Ziffern hat oder die Prüfung mit is_luhn nicht besteht.

Die Funktion soll die Anzahl der ungültigen Kreditkartennummern in der Datei zählen und als Ganzzahl int zurückgeben.
(Die Gültigkeit einer Kreditkartennummer bezieht sich ausschließlich auf die Länge und die korrekte Prüfziffer, nicht auf die tatsächliche Existenz der Karte. Alle in diesem Problem verwendeten Kartennummern sind fiktiv.)

Hinweise
  • Denken Sie daran, in Python können Dateien einfach gelesen werden, siehe https://docs.python.org/3/tutorial/inputoutput.html#reading-and-writing-files .
  • Denken Sie daran, Sie können eine Schleife verwenden, um auf einzelne Zeilen einer Datei zuzugreifen. Siehe https://docs.python.org/3/tutorial/controlflow.html#for-statements .
  • Jede gelesene Zeile endet mit "\n". Die String-Methoden str.strip() und str.replace(alt, neu) helfen Ihnen beim Bereinigen, siehe https://docs.python.org/3/library/stdtypes.html#string-methods .
  • Mit len(s) erhalten Sie die Anzahl der Zeichen eines Strings. Achten Sie genau auf die Grenzen: Nummern mit genau 12 und genau 19 Ziffern sind erlaubt.

  • Ihr Programm sollte keine Benutzereingabe verlangen, sondern nur die Funktion definieren. Sie können Ihr Programm testen, indem Sie den Dateinamen der zu testenden Datei als Kommandozeilenargument übergeben, z. B. python {{filename}} dateiname.txt ausführen.
  • Lassen Sie die Zeile if __name__ == "__main__": am Ende Ihrer Datei unverändert stehen, sonst kann die automatische Überprüfung Ihre Funktion nicht aufrufen.
  • Testen Sie Ihre Funktion zuerst mit der übersichtlichen Datei python {{filename}} small.txt. Sie enthält fünf Nummern, von denen zwei ungültig sind. Öffnen Sie die Datei im Editor und überlegen Sie, warum genau diese beiden ungültig sind. Sie können den Inhalt auch verändern, um weitere Testszenarien zu erzeugen.
  • Testen Sie anschließend mit python {{filename}} spaces.txt. Hier sind die Nummern durch Leerzeichen gruppiert, nur eine davon ist ungültig. Erhalten Sie als Ergebnis 5, entfernen Sie die Leerzeichen vermutlich nicht.
  • Testen Sie zum Schluss mit den umfangreichen Dateien python {{filename}} medium.txt und python {{filename}} large.txt.
  • Denken Sie auch an Grenzfälle: Nummern mit genau 11, 12, 19 und 20 Ziffern.

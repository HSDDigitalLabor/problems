Linked List in C

In dieser Aufgabe implementieren Sie eine einfach verkettete Liste (Singly Linked List) in der Programmiersprache C. Eine verkettete Liste besteht aus einzelnen Elementen, sogenannten Nodes. Jeder Knoten speichert einen ganzzahligen Wert (value) sowie einen Zeiger auf den nächsten Knoten (next). Die Liste selbst speichert einen Zeiger auf das erste Element (head). Ist die Liste leer, zeigt dieser Zeiger auf NULL.

Implementieren Sie die Funktionen, die in der vorgegebenen Datei linkedList.c deklariert sind. Die Funktionen sollen das Erstellen, Verändern, Durchsuchen und Löschen einer verketteten Liste ermöglichen.

Funktionsübersicht

  • createList() – Erstellt eine neue, leere Liste. Der Zeiger head muss initial auf NULL zeigen.
  • create(int value) – Erstellt einen neuen Knoten mit dem übergebenen Wert. Der Zeiger next muss initial auf NULL zeigen.
  • insert(List *list, int value) – Fügt einen neuen Knoten am Ende der Liste ein.
  • search(List *list, int value) – Sucht nach einem Knoten mit dem angegebenen Wert und gibt einen Zeiger auf diesen zurück. Wird kein passender Knoten gefunden, wird NULL zurückgegeben.
  • removeNode(List *list, Node *element) – Entfernt den angegebenen Knoten aus der Liste und gibt dessen Wert zurück. Kann der Knoten nicht entfernt werden, wird -1 zurückgegeben.
  • length(List *list) – Gibt die Anzahl der Elemente in der Liste zurück.
  • get(List *list, int index) – Gibt einen Zeiger auf den Knoten an der angegebenen Position zurück. Der Index beginnt bei 0. Bei einem ungültigen Index wird NULL zurückgegeben.
  • destroy(List *list) – Gibt den Speicher aller Knoten sowie der Liste selbst frei.
Hinweise
  • Verwenden Sie malloc(), um Speicher für neue Listen und Knoten zu reservieren.
  • Überprüfen Sie nach jedem Aufruf von malloc(), ob die Speicherreservierung erfolgreich war. Im Fehlerfall gibt malloc() den Wert NULL zurück.
  • Verwenden Sie free(), um nicht mehr benötigten Speicher freizugeben.
  • Achten Sie beim Entfernen eines Knotens darauf, die Verkettung der verbleibenden Knoten korrekt wiederherzustellen.
  • Eine Liste kann leer sein. Behandeln Sie daher insbesondere den Fall list->head == NULL.
  • Achten Sie auf gültige Zeiger und vermeiden Sie Zugriffe auf bereits freigegebenen Speicher.
  • Die Funktionen sollen auch mit ungültigen Eingaben wie NULL-Zeigern umgehen können, soweit dies in ihrer jeweiligen Implementierung sinnvoll ist.

Speicherverwaltung und Zeiger

Bei dieser Aufgabe verwalten Sie den Speicher selbst. Beachten Sie daher folgende Regeln:

  • Jeder mit malloc() erzeugte Knoten muss genau einmal mit free() freigegeben werden.
  • Wenn ein Knoten mit removeNode() aus der Liste entfernt wird, muss auch dessen Speicher freigegeben werden. Der zurückgegebene Wert muss daher vor dem Aufruf von free() zwischengespeichert werden.
  • Die Funktion destroy() muss alle noch in der Liste enthaltenen Knoten sowie die Listenstruktur selbst freigeben.
  • Ein Knoten darf nach seiner Freigabe nicht mehr verwendet oder dereferenziert werden.
  • Die Funktion removeNode() darf nur Knoten entfernen, die tatsächlich zu der übergebenen Liste gehören.
  • Die Funktion destroy(NULL) muss ohne Fehler aufgerufen werden können.

Hinweis: Der Wert -1 ist in dieser Aufgabe als Fehlerwert für removeNode() reserviert und darf deshalb nicht als regulärer Wert eines Knotens verwendet werden.

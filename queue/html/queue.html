Queue in C

In dieser Aufgabe implementieren Sie eine Queue (Warteschlange) in der Programmiersprache C. Eine Queue ist eine Datenstruktur, die nach dem FIFO-Prinzip funktioniert (First In, First Out). Das bedeutet: Das Element, das zuerst eingefügt wurde, wird auch zuerst wieder entfernt.

Eine Queue besteht aus einzelnen Elementen, sogenannten Nodes. Jeder Knoten speichert einen ganzzahligen Wert (value) sowie einen Zeiger auf den nächsten Knoten (next). Die Queue selbst verwaltet zwei Zeiger: head zeigt auf das erste Element, das als Nächstes entfernt wird. tail zeigt auf das letzte Element, an dem neue Elemente eingefügt werden.

Ist die Queue leer, zeigen sowohl head als auch tail auf NULL.

Implementieren Sie die Funktionen, die in der vorgegebenen Datei queue.c deklariert sind. Die Funktionen sollen das Erstellen, Einfügen, Entfernen und Auslesen von Elementen einer Queue ermöglichen.

Funktionsübersicht

  • createQueue() - Erstellt eine neue, leere Queue. Die Zeiger head und tail müssen initial auf NULL zeigen.
  • create(int value) - Erstellt einen neuen Knoten mit dem übergebenen Wert. Der Zeiger next muss initial auf NULL zeigen.
  • enqueue(Queue *queue, int value) - Fügt einen neuen Knoten am Ende der Queue ein. Die Funktion gibt die Queue zurück. Bei einer ungültigen Queue wird NULL zurückgegeben.
  • dequeue(Queue *queue) - Entfernt das erste Element der Queue und gibt dessen Wert zurück. Ist die Queue leer oder ungültig, wird -1 zurückgegeben.
  • peek(Queue *queue) - Gibt den Wert des ersten Elements zurück, ohne es zu entfernen. Ist die Queue leer oder ungültig, wird -1 zurückgegeben.
  • length(Queue *queue) - Gibt die Anzahl der Elemente in der Queue zurück. Bei einer ungültigen Queue wird 0 zurückgegeben.
  • destroy(Queue *queue) - Gibt den Speicher aller Knoten sowie der Queue selbst frei.
Hinweise
  • Verwenden Sie malloc(), um Speicher für neue Queues und Knoten zu reservieren.
  • Überprüfen Sie nach jedem Aufruf von malloc(), ob die Speicherreservierung erfolgreich war. Im Fehlerfall gibt malloc() den Wert NULL zurück.
  • Verwenden Sie free(), um nicht mehr benötigten Speicher freizugeben.
  • Neue Elemente werden immer am Ende der Queue eingefügt. Verwenden Sie dafür den Zeiger tail.
  • Elemente werden immer am Anfang der Queue entfernt. Verwenden Sie dafür den Zeiger head.
  • Achten Sie darauf, dass beim Einfügen in eine leere Queue sowohl head als auch tail auf den neuen Knoten zeigen.
  • Wird das letzte Element entfernt, müssen sowohl head als auch tail wieder auf NULL zeigen.
  • Achten Sie auf gültige Zeiger und vermeiden Sie Zugriffe auf bereits freigegebenen Speicher.
  • Die Funktionen sollen auch mit ungültigen Eingaben wie NULL-Zeigern umgehen können.

Speicherverwaltung und Zeiger

Bei dieser Aufgabe verwalten Sie den Speicher selbst. Beachten Sie daher folgende Regeln:

  • Jeder mit malloc() erzeugte Knoten muss genau einmal mit free() freigegeben werden.
  • Wenn ein Knoten mit dequeue() aus der Queue entfernt wird, muss auch dessen Speicher freigegeben werden. Der gespeicherte Wert muss daher vor dem Aufruf von free() zwischengespeichert werden.
  • Die Funktion destroy() muss alle noch in der Queue enthaltenen Knoten sowie die Queue-Struktur selbst freigeben.
  • Ein Knoten darf nach seiner Freigabe nicht mehr verwendet oder dereferenziert werden.
  • Die Funktion destroy(NULL) muss ohne Fehler aufgerufen werden können.
  • Wenn beim Einfügen eines neuen Knotens die Speicherreservierung fehlschlägt, darf die bestehende Queue nicht verändert werden.

Hinweis: Der Wert -1 ist in dieser Aufgabe als Fehlerwert für dequeue() und peek() reserviert und darf deshalb nicht als regulärer Wert eines Knotens verwendet werden.

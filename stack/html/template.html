In dieser Aufgabe implementieren Sie einen Stack (Stapel) in der Programmiersprache C. Ein Stack ist eine Datenstruktur, die nach dem LIFO-Prinzip funktioniert (Last In, First Out). Das bedeutet: Das Element, das zuletzt eingefügt wurde, wird auch zuerst wieder entfernt.

Ein Stack besteht aus einzelnen Elementen, sogenannten Nodes. Jeder Knoten speichert einen ganzzahligen Wert (value) sowie einen Zeiger auf den nächsten Knoten (next). Der Stack selbst verwaltet einen Zeiger: top zeigt auf das oberste Element des Stacks. Neue Elemente werden immer an dieser Position eingefügt und auch von dort wieder entfernt.

Ist der Stack leer, zeigt top auf NULL.

Implementieren Sie die Funktionen, die in der vorgegebenen Datei {{ filename }} deklariert sind. Die Funktionen sollen das Erstellen, Einfügen, Entfernen und Auslesen von Elementen eines Stacks ermöglichen.

Funktionsübersicht

  • createStack() - Erstellt einen neuen, leeren Stack. Der Zeiger top muss initial auf NULL zeigen.
  • create(int value) - Erstellt einen neuen Knoten mit dem übergebenen Wert. Der Zeiger next muss initial auf NULL zeigen.
  • push(Stack *stack, int value) - Fügt einen neuen Knoten oben auf dem Stack ein. Die Funktion gibt den Stack zurück. Bei einem ungültigen Stack wird NULL zurückgegeben. Schlägt die Speicherreservierung fehl, bleibt der Stack unverändert.
  • pop(Stack *stack) - Entfernt das oberste Element des Stacks und gibt dessen Wert zurück. Ist der Stack leer oder ungültig, wird -1 zurückgegeben.
  • peek(Stack *stack) - Gibt den Wert des obersten Elements zurück, ohne es zu entfernen. Ist der Stack leer oder ungültig, wird -1 zurückgegeben.
  • length(Stack *stack) - Gibt die Anzahl der Elemente im Stack zurück. Bei einem ungültigen Stack wird 0 zurückgegeben.
  • destroy(Stack *stack) - Gibt den Speicher aller Knoten sowie des Stacks selbst frei.
Hinweise
  • Verwenden Sie malloc(), um Speicher für neue Stacks und Knoten zu reservieren.
  • Überprüfen Sie nach jedem Aufruf von malloc(), ob die Speicherreservierung erfolgreich war. Im Fehlerfall gibt malloc() den Wert NULL zurück.
  • Verwenden Sie free(), um nicht mehr benötigten Speicher freizugeben.
  • Neue Elemente werden immer oben auf dem Stack eingefügt. Verwenden Sie dafür den Zeiger top.
  • Beim Einfügen eines neuen Knotens muss dessen next-Zeiger auf das bisherige oberste Element zeigen. Anschließend wird top auf den neuen Knoten gesetzt.
  • Elemente werden immer oben vom Stack entfernt. Aktualisieren Sie dafür den Zeiger top auf den nächsten Knoten.
  • Wird das letzte Element entfernt, muss top wieder auf NULL zeigen.
  • Achten Sie auf gültige Zeiger und vermeiden Sie Zugriffe auf bereits freigegebenen Speicher.
  • Die Funktionen sollen auch mit ungültigen Eingaben wie NULL-Zeigern umgehen können.

Speicherverwaltung und Zeiger

Bei dieser Aufgabe verwalten Sie den Speicher selbst. Beachten Sie daher folgende Regeln:

  • Jeder mit malloc() erzeugte Knoten muss genau einmal mit free() freigegeben werden.
  • Wenn ein Knoten mit pop() aus dem Stack entfernt wird, muss auch dessen Speicher freigegeben werden. Der gespeicherte Wert muss daher vor dem Aufruf von free() zwischengespeichert werden.
  • Die Funktion destroy() muss alle noch im Stack enthaltenen Knoten sowie die Stack-Struktur selbst freigeben.
  • Ein Knoten darf nach seiner Freigabe nicht mehr verwendet oder dereferenziert werden.
  • Die Funktion destroy(NULL) muss ohne Fehler aufgerufen werden können.
  • Wenn beim Einfügen eines neuen Knotens die Speicherreservierung fehlschlägt, darf der bestehende Stack nicht verändert werden.

Hinweis: Der Wert -1 ist in dieser Aufgabe als Fehlerwert für pop() und peek() reserviert und darf deshalb nicht als regulärer Wert eines Knotens verwendet werden.

Ausgangscode

Verwenden Sie den folgenden Code als Ausgangspunkt für Ihre Implementierung. Ergänzen Sie die Funktionskörper an den entsprechend gekennzeichneten Stellen.

Ausgangscode anzeigen 
#include <stdio.h>
#include <stdlib.h>

#ifndef STACK_TYPES_DEFINED
#define STACK_TYPES_DEFINED

typedef struct Node {
  int value;
  struct Node *next;
} Node;

typedef struct Stack {
  Node *top;
} Stack;

Stack *createStack(void);
Node *create(int value);
Stack *push(Stack *stack, int value);
int pop(Stack *stack);
int peek(Stack *stack);
int length(Stack *stack);
void destroy(Stack *stack);

#endif

Stack *createStack(void) {}

Node *create(int value) {}

Stack *push(Stack *stack, int value) {}

int pop(Stack *stack) {}

int peek(Stack *stack) {}

int length(Stack *stack) {}

void destroy(Stack *stack) {}

int main(void) {}

  • Nutzen Sie Ihre main-Methode, um Ihre Testfälle zu implementieren.
  • Kompilieren Sie Ihr Programm mit:
    clang -Wall -Wextra -Werror stack.c -o stack
    Beheben Sie alle Compilerfehler und Warnungen.
  • Testen Sie zunächst das Erstellen eines leeren Stacks. Nach dem Aufruf von createStack() muss top == NULL gelten.
  • Fügen Sie mehrere Elemente ein, beispielsweise die Werte 5, 10 und 15. Überprüfen Sie anschließend, ob top auf 15 zeigt und die folgenden Knoten die Werte 10 und 5 enthalten.
  • Testen Sie peek(). Die Funktion soll den Wert des obersten Elements zurückgeben, ohne den Stack zu verändern.
  • Testen Sie pop(), indem Sie mehrere Elemente entfernen. Die Werte müssen in umgekehrter Reihenfolge ihrer Einfügung zurückgegeben werden (LIFO-Prinzip). Bei den eingefügten Werten 5, 10 und 15 muss die Reihenfolge also 15, 10, 5 sein.
  • Entfernen Sie alle Elemente und überprüfen Sie, ob anschließend top auf NULL zeigt.
  • Fügen Sie nach dem vollständigen Leeren des Stacks erneut ein Element ein. Überprüfen Sie, ob top korrekt aktualisiert wird.
  • Testen Sie length() mit einem leeren und einem gefüllten Stack.
  • Testen Sie pop() und peek() mit einem leeren Stack. Beide Funktionen sollen -1 zurückgeben.
  • Testen Sie destroy() sowohl mit einem leeren als auch mit einem gefüllten Stack.

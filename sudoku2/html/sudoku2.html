Sudoku 2

Beim Lösen eines Sudoku-Rätsels ist es wichtig sicherzustellen, dass das Sudoku-Feld gültig ist. Für diese Aufgabe sollen Sie nur die 3x3-Subgrids überprüfen:

  • Jedes 3x3-Block darf jede Ziffer 1-9 höchstens einmal enthalten.

Ihre Aufgabe ist es, eine Funktion isValidBlock(board) zu implementieren, die ein 9x9-Sudoku-Board (als Liste von Listen mit Strings) entgegennimmt und True zurückgibt, wenn alle 3x3-Blocks gültig sind, ansonsten False. Leere Felder sind durch "." dargestellt.

Hinweise
  • Verwenden Sie keine Funktionen wie .count() oder .index(). Arbeiten Sie stattdessen mit Schleifen und Vergleichen.
  • Leere Felder (".") sollten ignoriert werden.
  • Jedes Element des Boards ist ein String, nicht eine Zahl.
  • Denken Sie daran, dass jedes 3x3-Subgrid durch die Zellen board[r][c] bestimmt wird, wobei r die Zeilennummer (0 bis 8) und c die Spaltennummer (0 bis 8) ist. Um herauszufinden, in welchem 3x3-Block eine Zelle liegt, können Sie die ganzzahlige Division // verwenden:
    • r // 3 gibt die Block-Zeile (0 bis 2) an
    • c // 3 gibt die Block-Spalte (0 bis 2) an
    Beispielsweise gehören die Zellen mit r = 0..2 und c = 0..2 zum oberen linken 3x3-Block. So können Sie die Zellen jedes Blocks systematisch überprüfen, ohne Zeilen oder Spalten zu beachten.

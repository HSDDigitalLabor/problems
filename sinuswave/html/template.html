Eine Look-Up-Tabelle (LUT) für eine Sinusfunktion enthält diskrete Werte einer vollständigen Sinusperiode. Solche Tabellen werden häufig in der digitalen Signalverarbeitung, bei der Klangsynthese oder in eingebetteten Systemen verwendet, um Sinuswerte effizient bereitzustellen.

  • Berechnen Sie für eine vorgegebene Anzahl von Punkten num_points gleichmäßig verteilte Stützstellen über eine vollständige Periode der Sinusfunktion, also im Bereich von 0 bis \(2\pi\).
  • Skalieren Sie die berechneten Sinuswerte aus dem Bereich [-1, 1] ohne Gleichanteil (DC-Offset) in den symmetrischen Bereich [-MaxAmplitude, MaxAmplitude]. Die Ergebnisse sollen als vorzeichenbehaftete Ganzzahlen gerundet werden.
    Beispiel: Bei einer Maximalamplitude von 32767 schwingt das Signal symmetrisch um den Nullpunkt zwischen -32767 und 32767.
  • Schreiben Sie zu Beginn der Datei den COE-Header: 
    memory_initialization_radix=16;
memory_initialization_vector=
  • Stellen Sie die Werte als 16-Bit-Zweierkomplement im 4-stelligen Hexadezimalformat (z. B. 7FFF bzw. 8001) dar und speichern Sie diese im COE-Vektorformat (jede Zeile endet mit einem Komma, die letzte Zeile mit einem Semikolon) in der Datei sinus_lut.coe.

{% include "file.html" %} implementieren Sie eine Funktion def generateLUT(num_points, max_amplitude):, die eine vollständige Sinus-Look-Up-Tabelle erzeugt.

Die Funktion erhält als Argumente:

  • num_points: Anzahl der Stützstellen einer vollständigen Periode
  • max_amplitude: Maximalwert der Amplitude (z. B. 32767 für 16-Bit-Signed-Werte)

Die Funktion soll die erzeugte Look-Up-Tabelle in der Datei sinus_lut.coe im aktuellen Verzeichnis speichern. Die Argumente sind auf Gültigkeit zu prüfen. Im Fehlerfall soll eine ValueError Exception ausgelöst werden.

Hinweise
  • Verwenden Sie zur Berechnung der Sinuswerte das Modul math, insbesondere die Funktion math.sin().
  • Denken Sie daran, dass Werte passend gerundet und anschließend als Ganzzahlen verarbeitet werden sollen.
  • Vergessen Sie nicht die beiden Headerzeilen memory_initialization_radix=16; und memory_initialization_vector= vor dem eigentlichen Datenvektor.
  • Negative Zahlen können im 16-Bit-Zweierkomplement über die Bitmaske & 0xFFFF in Python einfach als 4-stelliger Hex-Wert (z. B. mit f"{val & 0xFFFF:04X}") formatiert werden.
  • Achten Sie auf das Trennzeichen am Zeilenende: Alle Einträge werden durch ein Komma , getrennt, der letzte Eintrag wird mit einem Semikolon ; abgeschlossen.
  • Prüfen Sie sorgfältig, ob die Eingabewerte sinnvoll sind, z. B. ob die Anzahl der Punkte größer als 0 ist und der Maximalwert der Amplitude positiv ist.
  • Denken Sie daran, Python bietet die Möglichkeit Fehlermeldungen zu generieren, siehe docs.python.org/3/tutorial/errors.html#raising-exceptions .

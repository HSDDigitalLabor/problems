Die Mitternachtsformel (auch abc-Formel) ist eine Lösungsformel für quadratische Gleichungen der allgemeinen Form: ax² + bx + c = 0

\( ax^2+bx+c \)

\( x_{1,2}= \frac{-b \pm \sqrt{b^2-4ac}}{2a} \)

{% include "file.html" %} implementieren Sie ein Programm, dass den Benutzer zuerst nach einer Eingabe für den Wert für a, dann für den Wert für b und schlussendlich für den Wert für c fragt.

Anschließend soll Ihr Programm die Lösungen der quadratischen Gleichung mithilfe der Mitternachtsformel berechnen. Abhängig von der Anzahl der reellen Lösungen soll das Programm die entsprechende Anzahl und die berechneten Lösungen ausgeben. Überlegen Sie, welche Bedingungen erfüllt sein müssen damit

Dabei sind drei Fälle zu unterscheiden:

  • Keine Lösung: Geben Sie Keine Lösung auf der Konsole aus.
  • Eine Lösung: Berechnen Sie diese Lösung und geben Sie sie als Eine Lösung: x = ... aus.
  • Zwei Lösungen: Berechnen Sie beide Lösungen und geben Sie sie als Zwei Lösungen: x1 = ..., x2 = ... aus.
Hinweise
  • Lesen Sie die Werte für a, b, c über die Konsole ein. Nutzen Sie dazu die input()-Funktion. Bei den Werten kann es sich um Zahlen mit Nachkommastellen handeln.
  • Berechnen Sie zunächst den Ausdruck unter der Wurzel: b² - 4ac. Dieser wird auch als Diskriminante bezeichnet.
  • Beachten Sie, dass das math-Modul eine Funktion beinhaltet, um die Wurzel einer Zahl zu berechnen. Siehe math.sqrt().
  • Verwenden Sie math.sqrt() nur dann, wenn die Diskriminante größer oder gleich 0 ist.

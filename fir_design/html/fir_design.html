FIR-Tiefpass entwerfen

Ein idealer Tiefpass besitzt eine unendlich lange Impulsantwort in Form einer Si-Funktion. Für einen FIR-Filter begrenzen Sie die Impulsantwort mit einem Fenster auf eine endliche Anzahl von Koeffizienten.

Sie vergleichen einen abrupten Abbruch durch ein Rechteckfenster mit dem sanften Auslaufen eines Kaiser-Fensters. Eine Frequenzmaske legt fest, wie stark der Betragsgang von den Sollwerten abweichen darf.
